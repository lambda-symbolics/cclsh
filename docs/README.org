#+TITLE: cclsh documentation

* User documentation

- [[file:installation.org][Installation]] covers the Nix package, CCL and SBCL
  source launchers, and shared login-shell deployment.
- [[file:guide.org][User guide]] covers command syntax, Lisp evaluation, pipelines,
  custom commands, job control, completion, configuration and scripting.
- [[file:../examples/startup.lisp][Example startup file]] is a safe base for
  =~/.config/cclsh/startup.lisp=.
- [[file:installation.org::*Experimental prewarmed launcher][Prewarmed launcher]]
  documents the opt-in daemon, direct fallback and terminal limits.
- [[file:daemon.org][Shared SBCL daemon]] covers multiple terminal sessions in one
  image, shared definitions and error boundaries.

A concise built-in manual is available inside cclsh with =help=, or from
another shell with =cclsh help= and =cclsh help SECTION=.

* Maintainer documentation

- [[file:power.org][Idle power audit]] records wakeup fixes and session measurements.
- [[file:../patches/README.org][CCL patch ledger]] records downstream patch
  provenance, hashes and validation.
- [[file:yew-lish-adaptation.org][Yew and Lish adaptation report]] evaluates
  upstream shell and line-editor ideas for cclsh and Clinedi.
