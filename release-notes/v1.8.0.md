# CCLSH 1.8.0

- Keep the shared session server alive across clients that give up or connect without being the socket's owner; such connections are dropped instead of ending the service.
- Close the listener before shutting sessions down and exit the server process at the end, so a wedged session can no longer leave a server holding the socket and its clients waiting.
- Record the server's pid next to the socket; `cclshd start` probes a server for one second and retires an unresponsive one before starting a fresh server.
- Serve sessions from the saved image (`CCLSH_SERVER_MODE=run`, `CCLSH_IMAGE` in `cclshd`), so the first terminal of a login starts in a fraction of a second instead of loading the systems through ASDF.
- Use one socket directory per user regardless of the session environment, so a server prewarmed at boot or started over ssh is the one a desktop terminal attaches to.
